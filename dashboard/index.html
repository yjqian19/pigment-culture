This interactive dashboard visualizes blue pigment usage across 143 paintings from 6 cultures.

How to Use:

  • Hover over any point to see the painting title and object type
  • Click on a point to view detailed information and the painting image
  • Zoom and pan using the Plotly controls in the top-right corner

Visualization Method:

Points are positioned using semantic similarity of blue object types (via UMAP dimensionality reduction). Similar objects cluster together. Colors indicate cultural origin.
